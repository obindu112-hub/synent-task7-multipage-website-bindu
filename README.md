LearnPath – Student Learning & Career Guidance Website

About the Project

LearnPath is a multi-page website developed as Task 7 of the Synent Technologies Web Development Internship. It provides students with learning resources, career guidance, and interactive tools to track their learning progress.

Features

- Home Page: Introduces the website and highlights its main features.
- About Page: Provides information about LearnPath and its purpose.
- Services Page: Displays services such as programming skills, aptitude preparation, placement preparation, resume building, project development, and career guidance.
- Contact Page: Includes a contact form with basic validation and a demo success message.
- Learning Dashboard: Allows students to track completed lessons and overall progress.
- Interactive Quiz: Includes a programming basics quiz to test knowledge.
- Progress Tracking: Saves completed lessons in browser local storage.
- Responsive Design: Adapts the layout to different screen sizes.
- Consistent Navigation: Allows users to move between the website's pages.

Technologies Used

- HTML5: Structures the web pages.
- CSS3: Provides styling, layout, and responsive design.
- JavaScript: Handles interactive features, quiz functionality, and progress tracking.
- Local Storage: Saves completed lesson information in the browser.

How to Run the Project

1. Download or clone this repository.
2. Open the project folder.
3. Open "index.html" in a web browser.
4. Use the navigation menu to explore the different pages.
5. Visit the Dashboard to track lessons and attempt the quiz.

Learning Outcomes

Through this project, I gained practical experience in creating multi-page websites, designing responsive layouts, handling form validation, manipulating the DOM, implementing interactive quizzes, and using browser local storage.
